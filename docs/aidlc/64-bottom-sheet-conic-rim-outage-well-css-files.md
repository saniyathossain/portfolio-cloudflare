# 64 — Bottom-sheet modal, conic rim, outage status well, CSS only in `.css` files

**Date:** 2026-11-25 · **Status:** applied (uncommitted until the owner says so)

## 1. Contact modal as a phone bottom sheet (`styles.css`, ≤ 640 px)
Attached to the bottom edge, large top corners, a grabber, `env(safe-area-inset-bottom)` padding, a full-height spring
slide-up, internal scroll (`max-height: calc(100dvh - 1rem)`) when the form outgrows the screen. Desktop is unchanged
(centred dialog). `prefers-reduced-motion` now also removes the slide (it had no guard before).

## 2. Conic specular rim
`.modal-panel` and the outage dialog swap the linear border-box rim for a `conic-gradient`: bright at the lit top-left and
bottom-right, tint-fringed either side, faint between. Static, no runtime cost.

## 3. Outage page: glass status well
A recessed frosted inset (light, never black) with three quiet lines — `GET <path>` (filled by the script), the status
(`500 Internal Server Error`) and `retry n/N · in Ns` (updates with the orb). The old `RETRY n/N` paragraph and footer
are gone. Copy lives in `errors.json` (`terminal.well.requestVerb`, schema updated); lines stagger in unless reduced motion.
